# 🏐 배구 실시간 기록

태블릿·PC 브라우저에서 배구 경기를 실시간으로 기록하고 통계를 보는 웹 앱입니다. 6인제(정규 경기)와 9인제(동호인·생활체육)를 지원합니다.

**바로 사용하기:** https://kjhyun0412.github.io/volleyball-tagging/

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 시작 화면. 6인제/9인제 선택, 사용 가이드, 5분 가이드 영상 |
| `배구 실시간 분석 - 6인제.html` | 6인제 기록 앱 (25점 3선승, 로테이션) |
| `배구 실시간 분석 - 9인제.html` | 9인제 기록 앱 (21점 2선승, 서브 타순) |
| `배구 실시간 기록 앱 사용 가이드.pdf` | 선수 등록부터 통계 저장까지 안내서 |
| `가이드영상/` | 5분 마스터 가이드 영상 |
| `amp-track.js` | Amplitude 이용 통계 스크립트 |
| `server.js`, `서버실행.bat` | 내 PC에서 실행하기 위한 간단한 서버 |

기록 데이터는 사용하는 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되지 않습니다.

## 내 PC에서 실행하기

1. [Node.js](https://nodejs.org/)를 설치합니다.
2. 이 저장소를 내려받습니다.
3. Windows에서는 `서버실행.bat`를 더블클릭합니다. 다른 환경에서는 아래 명령을 실행합니다.

```bash
node server.js
```

4. 브라우저에서 http://localhost:8000/ 을 엽니다.

## 이용 통계 수집 안내

이 앱은 방문, 클릭, 체류 시간, 가이드 영상 시청 시간 등을 Amplitude로 수집해 앱 개선에 사용합니다. 입력창에 쓴 내용은 수집하지 않습니다.

수집을 거부하려면 주소 뒤에 `?notrack=1`을 붙여 한 번 접속하세요. 그 브라우저에서는 이후 전송하지 않습니다(`?notrack=0`으로 해제). 코드를 내려받아 쓰는 경우 `amp-track.js`를 `index.html` 등에서 빼면 수집되지 않습니다.
